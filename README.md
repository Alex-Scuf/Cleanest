<summary><h1>How install</h1></summary>


<h3>Automatically</h3>
<b>
Just search "Cleanest" in Spicetify Marketplace and click on a download-button


<h3>Manually</h3>

  1.Download "color.ini", "user.css" and "theme.js"
  <br>
  2.Create a folder "Cleanest" on the way <em>"C:\Users\(your-username)\AppData\Roaming\spicetify\Themes\"</em> and drop all the downloaded files in there
  <br>
  3.Go to the Powershell and enter <em>"spicetify config current_theme Cleanest"</em>
  <br>
  4.Enter <em>"spicetify apply"</em>
  <br>
</b>
 </details>
